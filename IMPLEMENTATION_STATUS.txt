Page Component
    ↓
import { signUp } from '@/lib/api/auth'
    ↓
signUp({ email, password, role, ... })
    ↓
API Client adds token to headers
    ↓
Fetch request to /api/auth/register (or real backend)
    ↓
Mock handler OR Real Nest.js backend
    ↓
Response returned with token and user data
    ↓
Token stored in localStorage

================================================================================
TOKEN MANAGEMENT
================================================================================

STORAGE: localStorage (key: 'auth_token')

FLOW:
1. User signs up/logs in
2. API returns accessToken (JWT)
3. Frontend stores in localStorage
4. Every API request includes: Authorization: Bearer <token>
5. On logout, token cleared from localStorage

TOKEN STRUCTURE:
{
  "sub": "user_id",
  "email": "user@example.com",
  "role": "user|studio_owner|admin",
  "iat": 1234567890,
  "exp": 1234571490
}
