📍 USER JOURNEY

Sign Up Flow:
  User → /auth/sign-up
    ↓
  Fill form (email, password, role, name)
    ↓
  Validate input
    ↓
  Create account in Supabase Auth
    ↓
  Database trigger creates user profile
    ↓
  Send verification email
    ↓
  Redirect to /auth/sign-up-success
    ↓
  User verifies email
    ↓
  Ready to login

Login Flow:
  User → /auth/login
    ↓
  Enter email and password
    ↓
  Authenticate with Supabase
    ↓
  Session established
    ↓
  Redirect to /dashboard
    ↓
  Dashboard shows user profile
    ↓
  Can access protected routes

Password Reset Flow:
  User → /auth/forgot-password
    ↓
  Enter email
    ↓
  Send reset link via email
    ↓
  User clicks link in email
    ↓
  Redirect to /auth/reset-password
    ↓
  Enter new password
    ↓
  Update password
    ↓
  Redirect to /auth/reset-success
    ↓
  Can login with new password

Logout Flow:
  User → Click logout button
    ↓
  Sign out from Supabase
    ↓
  Session cleared
    ↓
  Redirect to /auth/login
    ↓
  Protected routes no longer accessible

💾 DATABASE SCHEMA

public.users Table:
  ├── id (UUID) → References auth.users(id)
  ├── email (TEXT) → User email
  ├── role (ENUM) → 'user' | 'studio_owner' | 'admin'
  ├── first_name (TEXT) → User's first name
  ├── last_name (TEXT) → User's last name
  ├── phone (TEXT) → User's phone number
  ├── avatar_url (TEXT) → Profile picture URL
  ├── is_email_verified (BOOLEAN) → Email verification status
  ├── created_at (TIMESTAMP) → Account creation time
  └── updated_at (TIMESTAMP) → Last update time

public.password_reset_tokens Table:
  ├── id (UUID) → Primary key
  ├── user_id (UUID) → References auth.users(id)
  ├── token (TEXT UNIQUE) → Reset token
  ├── expires_at (TIMESTAMP) → Token expiration
  ├── used_at (TIMESTAMP) → When token was used
  └── created_at (TIMESTAMP) → Token creation time

Database Trigger:
  ├── handle_new_user() → Auto-creates user profile on signup
  └── Extracts metadata (role, names) from auth user

RLS Policies:
  ├── Users can view their own profile
  ├── Users can update their own profile
  ├── Users can delete their own profile
  ├── Admins can view all users
  └── Users can view their own password reset tokens

🔧 API ENDPOINTS

POST /api/auth/password-reset
  Request:
    {
      "email": "user@example.com",
      "redirectUrl": "https://yoursite.com/auth/reset-password"
    }
  Response:
    {
      "success": true,
      "message": "Password reset email sent successfully"
    }

GET /api/auth/callback
  Query Parameters:
    • code → Authorization code from Supabase
    • next → Redirect destination (default: /dashboard)
  Function:
    • Exchanges code for session
    • Updates email verification status
    • Redirects to next parameter
